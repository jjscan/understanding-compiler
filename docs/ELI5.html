내가 이해하고 확인하기 쉽게 바꿔줘요.

📄

긴 글을 넣어요

“무슨 말인지 모르겠어.”

→
🔎

쉽게 풀어 보여줘요

설명 · 그림 · 원문 위치
확인할 곳도 표시해요.

→
🧑‍💼

내가 판단해요

“근거를 보고 결정하자.”

예를 들어 🏭

AI가 공장 개선 제안을 썼어요.

“이 시스템을 쓰면 불량이 줄어듭니다.”

돋보기는 이렇게 도와줘요.
어떤 시스템? → 그림으로 보기
왜 줄어들까? → 원문 근거 찾기
근거가 부족해? → 확인할 곳 표시

언제 쓰면 좋을까요?

AI가 만든 긴 설계서, 보고서, 답변을 읽고 승인하거나 결정하기 전에 써요.

💡 돋보기는 정답을 정해주지 않아요.
내가 근거를 확인하고 판단하도록 도와줘요.

공장 문장은 설명을 위한 가상 예시입니다. 실제 효과를 검증한 결과가 아닙니다.
