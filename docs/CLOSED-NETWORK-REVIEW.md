# 폐쇄망 안전성 검토

검토일: 2026-10-04 (Asia/Seoul)

판정: 로컬 검증·빌드·뷰어는 인터넷 없이 실행하도록 보완했다. 사내 LLM Host/API의 운영 안전성은 미검증이다.

| 발견 사항 | 조치 | 상태 |
|---|---|---|
| SVG 기본 출력에도 Mermaid CDN fallback 코드가 남음 | 동적 스크립트 로딩 제거, 자체 SVG만 사용 | 수정 |
| 뷰어에 외부 요청을 막는 정책 없음 | CSP: default-src/connect-src none, 정확한 script SHA-256만 허용, referrer 없음 | 수정 |
| 원문 경로가 작업 폴더 밖 파일·심링크를 가리킬 수 있음 | resolve 후 IR 폴더 내부 접근만 허용 | 수정 |
| 산출 경로의 기존 심링크를 따라 파일을 쓸 수 있음 | 산출 파일·diagrams 심링크와 폴더 밖 대상 거부 | 수정 |
| 스킬이 WebSearch/WebFetch와 외부 원문 다운로드를 지시함 | 기본 폐쇄망 계약, 내부 자료만 조회, 외부 API fallback 금지 | 지침 수정 |
| 사내 API 연결·인증·로그·보존 설정이 저장소에 없음 | Host 책임과 필요한 설정을 별도 문서로 명시 | 환경 검증 필요 |

검증 결과:

- 표준 라이브러리 unittest 15개 통과.
- Python socket 생성과 urllib 요청을 실패시키는 상태에서 빌드 통과.
- 상대·절대 경로 탈출, 외부 심링크 원문, 산출 파일 심링크 차단 검증.
- script 종료 태그·img 삽입 입력이 추가 script/resource 태그를 만들지 않음, CSP 해시 일치 검사.
- 예시 5개 재빌드 성공, 모든 뷰어 JavaScript 문법 검사 통과.
- 로컬 루프백 HTTP로 실제 브라우저 확인: 읽기 페이지, SVG 2개, 검토 모드 정상 표시. 관측된 warn/error 로그 없음.

테스트 한계:

- 위 브라우저 검증은 실제 사내 PC·브라우저 정책 또는 OS 전체 네트워크 차단 상태의 검증이 아니다.
- 외부 요청 차단 테스트는 Python 소켓/urllib 패치와 생성 HTML/CSP 검사이며 전체 네트워크 패킷 캡처는 수행하지 않았다.
- 실제 사내 LLM API endpoint, 인증, TLS, 외부 fallback/telemetry, 문서 반출 통제, 입력 로그·보존은 확인하지 않았다.
- 스킬 지침은 Host의 권한 통제를 대체하지 못한다. 악성 원문을 통한 LLM 도구 실행·파일 접근은 Host에서 제한해야 한다.
- 원문·IR·HTML은 원문을 포함한다. 기밀 등급, 저장 폴더 권한과 보존 정책을 동일하게 적용해야 한다.

실행 조건과 설정은 [폐쇄망 실행 계약](../references/closed-network.md)을 따른다.
